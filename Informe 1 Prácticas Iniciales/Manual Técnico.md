# Manual Técnico de Mantenimiento Preventivo de Laptop  
# Lenovo IdeaPad 3 14ADA05

# 1. Introducción

Las computadoras portátiles se han convertido en herramientas indispensables para actividades académicas, profesionales y personales. Debido al uso constante, estos dispositivos pueden acumular polvo, generar temperaturas elevadas y presentar desgaste en sus componentes internos, provocando disminución del rendimiento, fallas inesperadas o reducción de su vida útil.

El mantenimiento preventivo consiste en realizar una serie de procedimientos técnicos destinados a conservar el correcto funcionamiento de un equipo antes de que aparezcan fallas graves. Estas actividades incluyen limpieza interna y externa, revisión de componentes, eliminación de residuos, renovación de materiales térmicos y verificación del estado general del hardware.

La laptop Lenovo IdeaPad 3 14ADA05 cuenta con componentes electrónicos sensibles que requieren una manipulación adecuada para evitar daños. Aplicar buenas prácticas de mantenimiento permite mejorar la disipación del calor, prevenir fallos relacionados con temperatura, mantener el rendimiento del sistema y aumentar la duración del equipo.

Este manual presenta un procedimiento técnico completo para realizar mantenimiento preventivo en una Lenovo IdeaPad 3 14ADA05, utilizando herramientas adecuadas y siguiendo medidas de seguridad para proteger tanto al usuario como al dispositivo.

# 3. Conceptos fundamentales

## ¿Qué es una computadora?

Una computadora es un dispositivo electrónico capaz de recibir, procesar, almacenar y transmitir información mediante la ejecución de instrucciones proporcionadas por programas informáticos.

Está formada por dos elementos principales:

- **Hardware:** componentes físicos que pueden ser observados y manipulados.
- **Software:** conjunto de programas e instrucciones que permiten controlar el funcionamiento del hardware.

---

# Función principal de una computadora

La función principal de una computadora es procesar información para convertir datos de entrada en resultados útiles mediante operaciones realizadas por el procesador y otros componentes internos.

Entre sus funciones principales se encuentran:

- Procesamiento de datos.
- Almacenamiento de información.
- Ejecución de aplicaciones.
- Comunicación mediante redes.
- Creación y edición de contenido digital.

---

# Hardware

El hardware representa todos los componentes físicos de un equipo informático. Estos elementos permiten que la computadora pueda ejecutar tareas y almacenar información.

Ejemplos de hardware:

- Tarjeta madre.
- Procesador.
- Memoria RAM.
- Unidad de almacenamiento SSD.
- Batería.
- Sistema de enfriamiento.
- Pantalla.
- Teclado.

---

# Software

El software está compuesto por los programas y sistemas operativos que permiten utilizar los recursos del hardware.

Ejemplos:

- Sistemas operativos como Windows o Linux.
- Navegadores web.
- Programas de oficina.
- Aplicaciones educativas.
- Herramientas de mantenimiento.

# 4. Mantenimiento preventivo

## Definición

El mantenimiento preventivo es un conjunto de acciones realizadas periódicamente para conservar un equipo informático en buenas condiciones, prevenir fallas y garantizar un funcionamiento eficiente.

A diferencia del mantenimiento correctivo, que se realiza cuando un componente ya presenta problemas, el mantenimiento preventivo busca anticiparse a posibles daños.

---

# Importancia del mantenimiento preventivo

Realizar mantenimiento preventivo en una laptop permite:

- Evitar acumulación excesiva de polvo.
- Mejorar la circulación del aire interno.
- Reducir temperaturas elevadas.
- Prevenir fallos del hardware.
- Mantener un rendimiento adecuado.
- Detectar problemas antes de que sean más graves.

El polvo acumulado puede bloquear las salidas de aire y afectar directamente al sistema de refrigeración. Cuando el procesador alcanza temperaturas demasiado altas, el equipo puede reducir su rendimiento automáticamente o apagarse para evitar daños.

---

# Ventajas del mantenimiento preventivo

| Ventaja | Descripción |
|---|---|
| Mayor vida útil | Reduce el desgaste de componentes internos. |
| Mejor rendimiento | Permite que los componentes trabajen correctamente. |
| Menor temperatura | Favorece la disipación del calor generado. |
| Prevención de fallas | Detecta problemas antes de que sean críticos. |
| Ahorro económico | Reduce la necesidad de reparaciones costosas. |

# 5. Herramientas necesarias para el mantenimiento

| Herramienta | Función |
|---|---|
| Brocha de cerdas suaves | Permite retirar polvo acumulado sin dañar componentes delicados. |
| Alcohol isopropílico | Limpia residuos, grasa y suciedad sin dejar humedad excesiva. |
| Pasta térmica | Mejora la transferencia de calor entre el procesador y el disipador. |
| Hisopos | Facilitan la limpieza de zonas pequeñas y difíciles de alcanzar. |
| Destornilladores de precisión | Permiten retirar tornillos pequeños de la carcasa y componentes internos. |
| Pulsera antiestática | Evita descargas eléctricas que pueden dañar circuitos electrónicos. |
| Pinzas | Ayudan a manipular cables pequeños o piezas delicadas. |
| Organizadores de tornillos | Permiten clasificar tornillos para evitar pérdidas o errores durante el ensamblaje. |

# 6. Componentes internos de la Lenovo IdeaPad 3 14ADA05

## Tarjeta madre

**Función:**

La tarjeta madre es el circuito principal de la computadora. Se encarga de conectar y permitir la comunicación entre todos los componentes internos.

En ella se encuentran conexiones para:

- Procesador.
- Memoria RAM.
- Almacenamiento SSD.
- Sistema de energía.
- Tarjeta inalámbrica.

# Procesador (CPU)

**Función:**

El procesador es el componente encargado de ejecutar instrucciones y realizar operaciones matemáticas y lógicas.

Es considerado el cerebro de la computadora porque controla gran parte de los procesos realizados por el sistema.

# Memoria RAM

**Función:**

La memoria RAM almacena temporalmente los datos y programas que están siendo utilizados por el sistema.

Una mayor cantidad de memoria RAM permite ejecutar más aplicaciones simultáneamente.

Características:

- Memoria tipo SO-DIMM DDR4.
- Instalación mediante ranura interna.


# Unidad SSD M.2

**Función:**

El SSD M.2 es el dispositivo encargado de almacenar permanentemente el sistema operativo, programas y archivos personales.

Ventajas:

- Mayor velocidad que los discos mecánicos tradicionales.
- Menor consumo energético.
- Mayor resistencia ante movimientos.

# Batería interna

**Función:**

Proporciona energía eléctrica al equipo cuando no está conectado al cargador.

Durante el mantenimiento debe desconectarse para evitar riesgos eléctricos.

# Sistema de enfriamiento

**Función:**

El sistema de enfriamiento mantiene temperaturas adecuadas mediante la transferencia y expulsión del calor generado por el procesador.

Está compuesto principalmente por:

- Disipador.
- Ventilador.
- Conductos térmicos.

# Disipador

**Función:**

El disipador absorbe el calor producido por el procesador y lo transfiere hacia las zonas donde será eliminado mediante el flujo de aire.

# Ventilador

**Función:**

El ventilador genera movimiento de aire para expulsar el calor acumulado dentro del equipo.

Cuando acumula polvo puede disminuir su velocidad y provocar aumento de temperatura.

# Tarjeta Wi-Fi/Bluetooth

**Función:**

Permite la conexión inalámbrica del equipo mediante redes Wi-Fi y dispositivos Bluetooth.

# 7. Medidas de seguridad durante el mantenimiento

Antes de iniciar cualquier procedimiento es necesario aplicar medidas de seguridad para proteger el equipo.

## Desconectar completamente el equipo

- Apagar correctamente la laptop.
- Desconectar el cargador.
- Retirar dispositivos USB o accesorios externos.

## Retirar objetos metálicos personales

Se recomienda retirar:

- Anillos.
- Pulseras.
- Cadenas u otros accesorios metálicos.

Estos elementos pueden provocar cortocircuitos accidentales.

## Control de electricidad estática

La electricidad estática puede dañar componentes electrónicos sensibles.

Buenas prácticas:

- Utilizar pulsera antiestática.
- Trabajar sobre superficies no conductoras.
- Evitar tocar contactos metálicos de componentes.

## Organización del área de trabajo

El área debe mantenerse:

- Limpia.
- Iluminada.
- Ordenada.
- Libre de líquidos.

Los tornillos deben colocarse en recipientes separados para facilitar el ensamblaje.

# 8. Procedimiento de mantenimiento preventivo

## Paso 1: Preparación del área

1. Apagar completamente la laptop.
2. Desconectar el cargador.
3. Retirar dispositivos externos.
4. Preparar herramientas necesarias.
5. Colocar la computadora sobre una superficie estable.

## Paso 2: Retirar tapa inferior

1. Retirar cuidadosamente los tornillos inferiores.
2. Guardar cada tornillo identificado.
3. Separar la tapa inferior utilizando herramientas adecuadas sin aplicar fuerza excesiva.

## Paso 3: Identificación de componentes

Antes de retirar piezas se debe identificar:

- Batería.
- Ventilador.
- Disipador.
- RAM.
- SSD.
- Tarjeta Wi-Fi.
- Tarjeta madre.

Esto evita errores durante el proceso.

## Paso 4: Desconexión de batería

1. Desconectar el cable de batería de la tarjeta madre.
2. Evitar manipular componentes con el equipo conectado a energía.

## Paso 5: Limpieza interna

Utilizar:

- Brocha de cerdas suaves.
- Alcohol isopropílico.
- Hisopos.

Eliminar cuidadosamente:

- Polvo acumulado.
- Residuos alrededor del ventilador.
- Suciedad en conectores.

## Paso 6: Limpieza del ventilador y disipador

1. Sujetar las aspas del ventilador para evitar que giren libremente.
2. Retirar polvo acumulado.
3. Limpiar las salidas de aire.
4. Revisar que el ventilador gire correctamente.

## Paso 7: Cambio de pasta térmica

La pasta térmica permite mejorar la transferencia de calor entre el procesador y el disipador.

Procedimiento:

1. Retirar cuidadosamente el disipador.
2. Limpiar la pasta térmica antigua con alcohol isopropílico.
3. Esperar que la superficie quede seca.
4. Aplicar una pequeña cantidad de pasta térmica aproximadamente del tamaño de un grano de arroz.
5. Colocar nuevamente el disipador.

No se debe aplicar demasiada pasta térmica, ya que puede provocar una mala transferencia de calor.

## Paso 8: Reinstalación de componentes

Verificar:

- Conexión correcta de batería.
- Instalación adecuada del SSD.
- Memoria RAM correctamente colocada.
- Cables internos conectados.

## Paso 9: Ensamblaje final

1. Colocar nuevamente la tapa inferior.
2. Ajustar tornillos sin aplicar fuerza excesiva.
3. Revisar que no existan piezas sueltas.

## Paso 10: Pruebas de funcionamiento

Después del mantenimiento:

- Encender la laptop.
- Verificar inicio del sistema operativo.
- Revisar funcionamiento del teclado y pantalla.
- Confirmar que el ventilador trabaje correctamente.
- Revisar temperaturas del equipo.

# 9. Recomendaciones para prolongar la vida útil

- Realizar limpieza interna cada 6 a 12 meses dependiendo del ambiente de uso.
- Evitar utilizar la laptop sobre superficies que bloqueen la ventilación.
- Mantener actualizado el sistema operativo.
- Evitar golpes y movimientos bruscos.
- Utilizar cargadores compatibles.
- Realizar copias de seguridad periódicas.
- Mantener limpio el teclado y pantalla.

# 10. Errores comunes durante el mantenimiento

| Error | Consecuencia |
|---|---|
| Trabajar con el equipo conectado | Puede provocar cortocircuitos. |
| No controlar electricidad estática | Puede dañar componentes internos. |
| Aplicar demasiada pasta térmica | Puede afectar la transferencia de calor. |
| Forzar conectores | Puede romper componentes delicados. |
| Mezclar tornillos | Puede causar daños durante el ensamblaje. |
| Usar líquidos inadecuados | Puede provocar corrosión. |
